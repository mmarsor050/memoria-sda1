## Publicar en GitHub Pages (una vez)

1. En GitHub: **New repository** → nombre, por ejemplo `memoria-soporte` → **Public** → *Create*.
2. **Add file → Upload files** → arrastra `index.html`, `README.md` y la carpeta `croquis` → *Commit changes*.
3. **Settings → Pages** → *Source*: **Deploy from a branch** → *Branch*: `main` / `(root)` → *Save*.
4. Al cabo de 1–2 minutos aparece la dirección: `https://TU-USUARIO.github.io/memoria-soporte/`

## Cómo funciona

- **Nada se envía a ningún servidor.** Las respuestas se guardan en el navegador y en el **código** del alumno.
- **💾 Guardar código** → Copiar → pegarlo en un Documento de su Drive. **📂 Continuar** → pegar el último código.
- **Fotos y capturas**: cámara, archivo o Ctrl + V. No van dentro del código (sería enorme): se añaden antes de sacar el PDF, o se usa **☰ Más → Descargar archivo completo** (incluye fotos) y se sube a Drive.
- **Entrega**: página «Entregar» → **Sacar PDF** → «Guardar como PDF» → subir a Classroom. Pedir también el código en un comentario privado.
- **Profesor/a**: menú lateral → *Profesor/a* (o ☰ Más), pegar el código del alumno → ver y sacar PDF. No modifica nada guardado en tu ordenador.
- **A mano**: ☰ Más → **Imprimir la memoria en blanco**.
- Navegadores: Chrome o Edge actualizados (el código usa compresión del navegador).

## Hojas de croquis

Imprimir **al 100 %** (sin «ajustar a página») y **a doble cara**. Vistas a tamaño real (1:1, cuadro de 5 mm). Perspectiva: 1:1 en el soporte 2 y 1:2 en los soportes 1 y 3. Las cotas se escriben siempre con la medida real.
- Cara 1: alzado · perfil izquierdo / planta · perspectiva isométrica (sistema europeo).
- Cara 2: pasos, escala, leyenda y ejemplos.
- Perspectiva: ampliación en modo normal; en refuerzo solo se señala el cambio con flecha y número.
